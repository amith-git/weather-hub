# 🌤️ Weather-Hub

Welcome to **Weather-Hub** — a sleek, modern, and fully responsive weather dashboard that lets you check real-time weather for **any city in the world**. Built with **HTML, CSS, and JavaScript**, it fetches accurate data from **WeatherAPI** and presents it in an easy-to-read interface.
