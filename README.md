# 🌤️ Weather-Hub

Check real-time weather for **any city worldwide** with a sleek, responsive dashboard built using **HTML, CSS & JavaScript**. Powered by **WeatherAPI** for accurate data.  

[Live Demo](https://amith-git.github.io/weather-hub/) | [GitHub](https://github.com/amith-git/weather-hub)

---

## Features
- Search any city for current weather  
- View Humidity, Wind, Pressure, Clouds, Sunrise & Sunset  
- Responsive design for desktop, tablet & mobile  

---

## Tech
**HTML5 | CSS3 | JavaScript | WeatherAPI**
